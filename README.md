# Unmeshed

An overview of [Unmeshed](https://unmeshed.io/), the workflow orchestration platform for APIs, AI agents, batch jobs and human approvals, built by the team behind Netflix Conductor.

Published on Read the Docs: https://unmeshed.readthedocs.io/

- Website: https://unmeshed.io/
- Official documentation: https://unmeshed.io/docs/start-here/getting-started

## Build locally

```bash
pip install -r docs/requirements.txt
mkdocs serve
```
