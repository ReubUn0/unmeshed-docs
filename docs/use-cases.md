# Use cases

## API orchestration

Combine calls to several services into one fast endpoint, with data mapping, error policies and retries handled by the engine.

[Read the API orchestration guide](https://unmeshed.io/docs/use-cases/api-orchestration)

## Microservices orchestration

Coordinate long-running, multi-service business processes like order fulfilment or onboarding, with state persisted between steps.

[Read the microservices orchestration guide](https://unmeshed.io/docs/use-cases/microservices-orchestration)

## Scheduled and batch jobs

Replace cron, Windows Scheduler and Kubernetes CronJobs with visible, retryable schedules and cross-job dependencies.

[Read the scheduled jobs guide](https://unmeshed.io/docs/use-cases/scheduled-jobs)

## Migrating from Netflix Conductor

Move existing Conductor workflows onto a managed platform built by the same team.

[Read the Conductor migration guide](https://unmeshed.io/docs/use-cases/migrating-from-conductor)
