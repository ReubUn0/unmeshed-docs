# What makes Unmeshed different

## Built by the Netflix Conductor team

Unmeshed's founders built Netflix Conductor, so the platform starts from years of running orchestration at scale. Conductor users get a direct path across with the [Conductor migration guide](https://unmeshed.io/docs/authoring/conductor-migration-guide).

## Code, AI, rules and people in one workflow

Python and JavaScript steps, LLM calls, [decision tables](https://unmeshed.io/docs/concepts/decision-table-rules), human approvals and 100+ integrations all live in the same process definition. You don't stitch an AI tool, a rules engine and a job scheduler together.

## Workflows served as APIs

With [API Orchestration](https://unmeshed.io/products/api-orchestration), a workflow becomes a high-scale API endpoint that runs synchronously or asynchronously. That removes the need to build and maintain separate backend-for-frontend (BFF) services.

## Batch scheduling with agents on any server

Schedules run at second-level granularity. [Command agents](https://unmeshed.io/docs/agents/adding-agents-for-command-executions) run jobs on Linux, macOS, Windows and even [IBM i / AS400](https://unmeshed.io/docs/agents/ibmi-as400-agent-installation) machines, which makes Unmeshed a practical replacement for cron and legacy schedulers.

## Operations visibility built in

Every run has step-level replay, real-time state and audit logs. Operators can [hold](https://unmeshed.io/docs/how-to-guide/process-hold-steps) or skip steps in a live process, and teams can [create mock test cases](https://unmeshed.io/docs/how-to-guide/creating-mock-test-cases) for workflows.

## Predictable cost, deploy anywhere

No per-action or per-transition fees. Run it in Unmeshed's cloud or your own, and start on a free tier with 2,000 workflow executions a month. See [pricing](https://unmeshed.io/pricing).
